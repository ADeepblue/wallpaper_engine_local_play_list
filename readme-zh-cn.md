## Wallpaper Engine 本地图片循环播放器模板

这是一个 Wallpaper Engine 的简单模板，用于循环播放本地文件夹中的图片。

---

### 📂 添加图片

将你想要轮播的所有图片，放入本目录下的 **`img`** 文件夹中。  
支持的格式：PNG、JPG、JPEG、BMP、GIF、WebP（具体以 Wallpaper Engine 支持的格式为准）。

---

### ✏️ 修改壁纸标题

你可以通过以下两种方式更改壁纸在软件中显示的名称：

1. **直接编辑 `project.json`**  
   打开 `project.json` 文件，找到 `"description"` 字段，将其值改为你想要的标题即可。

2. **使用 Wallpaper Engine 编辑器**  
   - 在编辑器中打开本壁纸项目。  
   - 依次点击顶部菜单：**编辑 → 更改项目设置 → 常规**。  
   - 在 **“标题”** 输入框中修改名称。

---

### 🖼️ 更新预览缩略图

如果你想更换壁纸在软件选择界面中显示的预览图：

- 同样在 Wallpaper Engine 编辑器中，进入 **编辑 → 更改项目设置 → 常规**。  
- 找到 **“预览图片”** 区域，Wallpaper Engine 会自动帮你截取当前画面作为预览。  
- 你也可以手动选择其他图片作为预览图。
